# 🟣 Purple Sector — Formula 1 for the Fans

> **Formula 1 reimagined for the fans.** No telemetry overload, no gatekeeping — just authentic race results, interactive track maps, 3D pop-out driver cutouts, and pure racing thrills.

**Designed & built with ❤️ by Sarvesh**

---

## 🏎️ Features

- **2026 Grid & 11 Constructors**: Complete 22-driver grid including Kimi Antonelli, Lewis Hamilton in Ferrari, and the newly entered 11th team **Cadillac Formula 1 Team**.
- **Interactive SVG Circuit Maps**: All 26 world circuits mapped with GPS-accurate layout vectors, DRS zones, corner counts, official **Lap Records**, and **Pole Lap Benchmarks** (including Sepang & Bahrain).
- **Driver Detail Modals & Cutouts**: High-resolution 3D driver portrait stages displaying career championships, podiums, wins, poles, and natural aspect ratios.
- **Dynamic 2026 Season Hub**: Real-time Grand Prix countdown clocks, Sprint format flags, round-by-round calendar classifications, and interactive status filters.
- **Triple-Season Standings**: Instant toggle between 2026 live championship, 2025, and 2024 final classifications with championship progression graph and leader spotlight.
- **Legends Hall of Fame**: Every World Drivers' and World Constructors' Champion from 1950 to 2025 with decade filtering.
- **Head-to-Head Comparison**: Compare any two drivers side-by-side across career metrics, poles, race starts, and win percentages.
- **Gamified F1 IQ Quiz**: 10 interactive casual & expert trivia questions with instant explanations and rank certification.
- **F1 101 Casual Fan Guide**: Flags glossary, Pirelli tyre compound breakdown, points system, 2026 engine & active aero revolution, and essential paddock terminology.
- **Mobile First & Ultra-Fast**: Fluid layout verified across 320px–430px mobile viewports, GPU-accelerated micro-animations, and zero horizontal overflow.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Smooth Scroll**: [Lenis](https://lenis.darkroom.engineering/) (Desktop pointer devices)
- **Styling**: Vanilla CSS Design System with dark titanium palette (`#07040d`), custom 3-sector telemetry speed mark, Google Fonts (`Big Shoulders Display`, `Manrope`, `JetBrains Mono`).

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/itzsrv156/Purple-Sector.git

# Enter the project directory
cd Purple-Sector

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
